Race mockup
Race weekends. The Race tab is now a list of weekends you set up yourself, each kept with its own sessions, progress and results. Starting another one never means resetting the last.
  • Each card is the Results page's WeekendCard: the same photograph, layout outline, title and car line. Its rows list the sessions instead of results, each with its SessionStatusDot. A driven session shows its ResultCell, and one still to run shows its length.
  • The pill shows the weekend's state: Set up, In progress (primary), Finished (success). These three are a closed set, so they get colours. Set up is the neutral one on purpose: nothing has happened yet.
  • The footer has Continue on a weekend in progress and Open otherwise. The ⋯ menu holds Duplicate, Rename and Delete, and Duplicate copies the setup without the results. New race weekend creates one with today's defaults and opens it.
  • In-progress weekends sort first, then the most recently changed.
  • Only one launch can run at a time, across every weekend and the career. Launch is disabled elsewhere while one is waiting, and says which weekend has it.

Where a race starts from. The open race session gets a Grid part between Length and Conditions, as it has in the championship editor. What it offers depends on what runs before it.
  • Behind a qualifying, or an earlier race: the editor's own controls. Starts from picks the session, keeps how many carry over (empty means all), and reverses top how many of the front start in reverse. The editor's ReverseDiagram draws the result. You start wherever that session put you.
  • Nothing before it (a race on its own, or only practice before it, since practice sets no grid): You start is ChoiceChips with Last, Pole, Position and Random. Position adds a number box, and Random is seeded, so reloading doesn't move you. The AI line up on pace, as today.
  • Picking Not from a session in the Starts from menu gives the second set of controls even when a qualifying exists. That covers a practice-and-race weekend where the qualifying is only for show.
  • This uses startingPosition, which a race session already has and race.ini already writes. Today the weekend overwrites it with "last". The new part is only the grid choice that feeds it.

A driven race, on the weekend's page. The open session is the round page's SessionResult: ResultStrip, Podium and ClassificationTable, read off the archive the same way. The Result page of the Results tab opens this race the same way.
  • What changes for classes:
    • ResultStrip leads with your class position and puts the overall one beside it.
    • Podium shows your class's top three.
    • ClassificationTable gains a class column (the class chip and the class position) and a filter above it. The filter uses the calendar's Segments: Overall, then each class.
    • Filtering to a class greys nothing. It lists that class with its own gaps.
    • A single-class race shows none of this: no filter, no column, exactly the table it is today.
  • No points: a quick race scores none, so the table has no points column. ClassificationTable already leaves out every column a session has nothing for.
  • The same change reaches multi-class championships such as WEC and IMSA. Their round pages show one undivided table today.
  • The left column is the round page's WeekendList, headed by Weekend results once anything has run, as Round results heads a round.
