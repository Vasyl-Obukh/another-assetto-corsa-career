What changes with the name

  • Window title, start panel heading, setup rail: "Another Assetto Corsa Career" (app.title, setup.title, index.html). The window gets the mark as its icon (BrowserWindow.icon).
  • Slug another-assetto-corsa-career: package name, the GitHub repo, the drag format application/x-another-ac-career-row, and the docs (CLAUDE.md, ROADMAP.md, the mockups' title bars).
  • Data folder moves to %APPDATA%/another-assetto-corsa-career/, since Electron names it after the package. You rename the old %APPDATA%/another-assetto-corsa-career/ by hand; no migration code.

Notes

The mark

  • Apex A and Circuit A are track monograms; Rising stripes and Ladder A are the career climb. Ladder A is both at once: an A whose rungs are the ladder, the top one reached in kerb red.
  • Each mark has a second, bolder drawing for 16 and 24 px, where thin lines and small details turn to mush. All ship as SVG; the window and taskbar icon is an .ico built at 16, 24, 32, 48 and 256.
  • Bare, the mark is the theme's ink plus blue and kerb red. As the app icon it sits on the setup rail's blue-to-violet gradient.

The name logo

  • Set in Bahnschrift, Windows' own DIN and the face of most circuit signage. The shipped SVG has its text outlined, so it looks the same on any machine.
  • "Another" scrawled in by hand over a proofreader's caret, as if added to the title after the fact; one stroke of the same red marker under "Career", so the two read as one edit.
  • It is one fixed drawing per theme, never a screen's text, so it doesn't go through t(). A Ukrainian name, if wanted, would be a second drawing.
