# Missing tracks

Every track and layout the shipped championships would need to run their real calendars in full, with where each belongs in the calendar as shipped. Generated from the shipped rounds; round numbers are the ones the championship page shows.

Three kinds of gap are listed:

- **Missing venues** - circuits not in any content the app catalogues. Each names the round it would sit after, or the round currently standing in for it.
- **Catalogued but not yet raced** - Mexico City is in VRC's content now, so those rounds only need adding to the championship, not a mod.
- **Period layouts** - circuits raced on a later layout, with the laps covering the real distance. A period mod would make them exact.

Placements marked *position not checked* belong to seasons whose order was not verified, or to championships not tied to a season.
